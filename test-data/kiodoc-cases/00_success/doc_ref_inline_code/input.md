# Inline code and documentation links

An operator cannot contain `[` or `]`.
An opener contains `[` but no `]`.
The close replaces `[` with `]`.
`*[` pairs with `]*`, and `[%` pairs with `%]`.

Quoted `` [`missing`] `` and `` [`@signature missing`] `` are examples.
The real [`identity`] reference and [`@signature identity`] directive still work.
